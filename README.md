# Nutrio

Проект, выполненный в рамках учебной практики весной 2026 года.

Основной репозиторий находится на другой платформе и является приватным. Здесь размещена архивная версия проекта.

## Файлы

- **`nutrio.rar`** — исходный код проекта.
- **`Пономаренко_report.pdf`** — краткое описание выполненной работы.
- **`nutrio_presentation.pdf`** — презентация проекта с описанием его основных возможностей и моего вклада в общий результат.
